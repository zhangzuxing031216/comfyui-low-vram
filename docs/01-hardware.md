# 01 · 硬件与档位：先判断你的机器能跑什么

> 这一章不装软件，只做判断。判断错了，后面全是白费时间。

---

## 1. 三个关键数字

| 数字 | 在哪看 | 影响 |
|---|---|---|
| **显存 VRAM** | 任务管理器 → 性能 → GPU → 专用 GPU 内存 | 决定能不能装下模型 |
| **内存 RAM** | 任务管理器 → 性能 → 内存 | 低显存时模型会卸载到内存 |
| **硬盘空闲** | 资源管理器 | 模型很占空间 |

ComfyUI 的低显存模式不是“魔法”，它做的是：

```text
显存放不下的部分 → 临时放到内存
内存也不够 → 放到虚拟内存（硬盘）
```

所以显存小可以忍，**内存和硬盘也不能太小**。

## 2. 显存档位表

### 2.1 4GB（GTX 1650 / RTX 3050 4G / 核显共享）

能跑：

- SD1.5，512×512，20–30 步
- LCM 4 步快速出图
- 一个轻量 ControlNet
- 4 倍放大（分块）

不要碰：

- SDXL 1024
- SVD / Wan 视频
- Flux
- 批量 4 张

启动参数：

```bat
--novram --use-pytorch-cross-attention --reserve-vram 0.3
```

预期速度：512×512 / 20 步，约 15–40 秒（看 CPU 和内存）。

### 2.2 6GB（RTX 3060 Laptop / RTX 2060 / GTX 1660 Ti）

能跑：

- SD1.5 很顺（512–768）
- SDXL 768×768（Tiled VAE，慢）
- SDXL 1024 偶尔能跑，但不稳定
- AnimateDiff 16 帧、SVD 低分辨率
- ControlNet + 放大

不要碰：

- Wan 14B
- HunyuanVideo
- Flux dev fp16
- 长时间视频

启动参数：

```bat
--lowvram --use-pytorch-cross-attention
```

预期速度（实测 RTX 3060 Laptop 6GB）：

| 场景 | 耗时 |
|---|---|
| 512×512 / 20 步 | 约 7 秒 |
| 768×768 / 20 步 | 约 15 秒 |
| SDXL 768 / 25 步 | 约 40–90 秒 |
| SDXL + 放大到 2048 | 3–10 分钟 |

### 2.3 8GB（RTX 3060 Ti / 4060 / 3070 Laptop）

能跑：

- SDXL 1024 比较稳
- SD1.5 批量 2–4 张
- 短视频更从容
- 轻量 LoRA 叠加

启动参数：

```bat
--lowvram --use-pytorch-cross-attention
```

8GB 可以尝试 `--normalvram`，但如果开 ControlNet 或放大，还是 `--lowvram` 更稳。

### 2.4 12GB+

- SDXL 批量
- Flux fp8（仍然慢）
- 轻量视频
- 多 ControlNet

12GB 不是“为所欲为”，24GB 才是视频/Flux 的舒适区。

## 3. 内存要多少

| 内存 | 4GB 显存 | 6GB 显存 | 8GB 显存 |
|---|---|---|---|
| 8GB | 很勉强 | 不建议 | 不建议 |
| 16GB | 能跑 SD1.5 | 能跑，SDXL 吃力 | 能跑 |
| 32GB | 舒服 | 舒服 | 舒服 |
| 64GB | 过剩 | 过剩 | 视频更稳 |

**16GB 内存跑 SDXL 时**：

- 关掉浏览器多余标签页
- 关掉游戏、剪映、模拟器
- 虚拟内存调到 32–64GB

## 4. 虚拟内存怎么设（Windows 11）

低显存机器必做。否则会看到“内存不足”而不是“显存不足”。

1. 右键“此电脑” → 属性 → 高级系统设置。
2. 性能 → 设置 → 高级 → 虚拟内存 → 更改。
3. 取消“自动管理所有驱动器的分页文件大小”。
4. 选一个 **SSD** 盘（不要选机械盘）。
5. 自定义大小：
   - 初始大小：`32768` MB
   - 最大值：`65536` MB
6. 点“设置” → 确定 → 重启。

> 虚拟内存放 SSD 会占用空间，但比机械盘快很多。至少留 64GB 空闲。

## 5. 笔记本双显卡注意事项

很多游戏本有“核显 + 独显”：

- 浏览器/桌面可能跑在核显上。
- ComfyUI 必须跑在独显上。

检查：

```powershell
nvidia-smi
```

如果能看到 `python.exe` 进程，说明独显在工作。

如果 `torch.cuda.is_available()` 是 False：

1. NVIDIA 控制面板 → 管理 3D 设置 → 程序设置。
2. 添加 `python_embeded\python.exe`。
3. 首选图形处理器 → 高性能 NVIDIA 处理器。
4. 重启终端。

## 6. 硬盘怎么分

推荐：

```text
D:\ComfyUI\                 ← 程序 + 常用模型（SSD）
E:\ComfyUI-models\          ← 大模型仓库（SSD/HDD）
E:\ComfyUI-output\          ← 输出图（可定期清）
```

如果只有一块盘：

```text
D:\ComfyUI\
├─ ComfyUI\models\          ← 常用 3–5 个模型
└─ _archive\                ← 不常用的模型，用时再移回来
```

**不要把模型放在**：

- 中文路径
- 同步盘（OneDrive / 百度同步）里
- 网络驱动器里

这些都会导致加载慢或路径错误。

## 7. 一张表判断你该下哪个档位

| 你的情况 | profile | 额外 |
|---|---|---|
| 4GB 显存 / 8GB 内存 | `minimal` | 只跑 SD1.5，512 |
| 4GB 显存 / 16GB 内存 | `minimal` | 可以试 768 |
| 6GB 显存 / 16GB 内存 | `standard` | SDXL 用 768 |
| 6GB 显存 / 32GB 内存 | `standard` | SDXL 768 更稳 |
| 8GB 显存 / 16GB 内存 | `standard` | SDXL 1024 可试 |
| 8GB+ / 32GB+ / 想玩视频 | `standard` + `video` | 先跑通图再下视频 |
| 没有 N 卡 | 不装 | 用云端 / CPU 仅测试 |

## 8. 实测参考（RTX 3060 Laptop 6GB / 16GB RAM）

| 项目 | 结果 |
|---|---|
| ComfyUI 版本 | 0.42.1 便携版 |
| Python | 3.12（自带） |
| PyTorch | 2.x + cu12x |
| SD1.5 512×512 / 20 步 | 6.7 秒（热） |
| SD1.5 768×768 / 20 步 | 15.1 秒（热） |
| 首次出图（加载 2GB 模型） | 13.7 秒 |
| SDXL 768 + 放大 | 3–10 分钟 |
| 启动（干净安装） | 10–30 秒 |
| 启动（50 个插件） | 2–5 分钟 |

> 你的机器比这个快/慢都正常。先跑 512×512，再逐步加分辨率。

## 9. 什么时候该放弃本地

出现以下情况，建议直接用云端：

- 显存 < 4GB，且只是偶尔玩。
- 想跑 SDXL 1024 批量。
- 想跑 Wan / HunyuanVideo / Flux dev。
- 笔记本散热差，出图就降频。
- 电费/时间成本高于云端租卡。

云端选项（自行比价）：

- 智算云扉 / AutoDL / RunPod / Vast.ai / Google Colab
- 国内 ComfyUI 云平台（注意数据隐私）

本地适合：调试工作流、小图试片、隐私敏感素材。
云端适合：高分辨率批量、视频、大模型。
